You are continuing development of an **existing Phase 1 application** called:

IMPORTANT: **Do not rebuild the application from scratch.**

* React + Vite frontend
* Express backend
* PostgreSQL database
* Drizzle ORM
* Existing OpenAPI/API architecture
* Dashboard
* RFQ Inbox
* RFQ Detail pages
